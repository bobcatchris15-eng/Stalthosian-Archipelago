# Bounded Longstride wild caregiver draft

Planning assigns dependence to Longstride, not Smalltrotter. Smalltrotter offspring
remain independent. A normal fresh Longstride hatchling can bind once at entry to
one actual living retained adult Longstride. Only the young hero receives a supported
local birth pose; parent ID/species/position/needs/graph/session are unmodified.
This is a wild caregiver association, not evidence of biological lineage, egg laying,
feeding, predation or a general family framework. N clears the old association and
currently provides no new caregiver entry; this is an explicit limitation.

Young follow uses the existing HeroDestination/controller owner and supported local
route checks. Direct/player destination/own needs win. Separation keeps that exact
caregiver ID; no nearest-parent retarget. Actual death/missing/maturity ends care.
The caregiver is exempted from generic fear while locally recognized; other adult
Longstrides remain potential dangers. Actual parent body awareness uses peerLeads
only to exclude fear/other social commands: it never commands approach/wait toward
the young. Parent ordinary needs and single registry tick/contact ledger remain.
No extra actor, resource, session or simulation clock is created.

Focused domain test covers once-only birth binding, direct/destination/needs and
body/vertical/physical guards, no new-hero adoption, death/no-retarget, actual existing
NPC movement and accepted shared-water relief with old bindings/history retained.
Native build, composed acceptance and actual caregiver-follow distance remain root-owned.
