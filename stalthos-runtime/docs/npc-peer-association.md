# Bounded NPC peer association draft

Connected preview may form one session-only peer link between existing eligible
nearby conspecific NPC identities. NativePopulationRegistry remains the sole
mutable population/resource owner; the small association controller owns only a
RelationshipTracker-backed link and physical encounter time. It receives actual
ActorViews, never camera state or HeroSim perception. Original saved mode leaves
this feature disabled and retains its existing continuation contract.

The lowest eligible nearby identity leads. After a quiet encounter the leader
waits while the follower moves on the existing dry graph at proposed .7m/s and
pauses about3m away. A paused follower retains its in-flight edge. Need or hero
avoidance interruption resumes that edge before selecting another route; no
position/identity/resource copy or teleport is used. Hero-peer ownership also
suppresses conflicting NPC social commands. Hunger>.42, thirst>.48 or fatigue>.62
interrupt social activity. Resource relief still requires the existing bound
session, eligible physical contact and finite shared ledger.

PeerTuning supplies encounter9m, separation18m, quiet1.5 physical seconds and
wait3m; the NPC controller accepts a replacement tuning object. These are draft
parameters, not a model of real social biology. A separated pair retains its
identities and observes reunion if the actual bodies come back. Dead/absent or
busy actors cannot receive social motion. There is no kinship, mating, family,
search behavior, pair retargeting after death or connected save support.

## Diagnostic fixtures

Run-ConnectedWorld.ps1 -NpcPeerProbe/-NpcPeerCameraProbe/-NpcPeerNeedProbe
uses two existing Smalltrotter IDs, a supported position on the existing meadow
water-to-browse edge, satisfied needs (or a near-thirst threshold), a fixed hero
body and a noon renderer preview. The normal population seed, clocks, needs
rates, resources and interaction-session allocator are not replaced. The camera
variant starts the same actors/body and moves only the detached camera. This is
labelled synthetic actor/body/need placement, not natural-seeding evidence.

Native JSON/captures and the current task receipt describe actual verified
scope. Endpoint framing, gait/sole contact and earlier accepted world roughness
remain draft limitations. Unit/domain separation/reunion is distinct from a
native long departure/return route. Do not infer full social AI, full game,
visual acceptance or30FPS from these checks.
