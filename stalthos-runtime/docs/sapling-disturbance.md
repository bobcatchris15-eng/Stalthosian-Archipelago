# One body-local sapling disturbance: working draft

In normal connected mode, approach the existing sapling9006 at148,40 with the
living supported hero. Body-focus **F** deliberately disturbs it within1.8m
horizontal/.9m vertical reach. The readable cue appears from body proximity;
camera proximity does not enable the action. This is a proximity interaction,
not physical impact, trunk collision or an authored contact animation.

SaplingDisturbance records StandingDamaged under existing world tree identity9006
in region1001, timestamped by the actual calendar. Repeat actions leave revision
and timestamp unchanged. Native presentation queries that world exception and
applies a.32radian root lean and per-object tint(1,.35,.12,1) to that instance.
Shared meshes, materials, prototype objects, asset files and nine other tree
instances remain unchanged. This simple replaceable representation is not tree
mechanics or art acceptance. Existing layout and reach remain easy to tune.

synthetic F actions at physical3 and after return. Proxy reverses4..7 and returns

The exception survives departure/return in the running connected world. Connected
saves remain refused; original saved-mode behavior is unchanged. No forest
ecology, general destruction, sapling healing, impact animation or new collision
framework is added. New-hero world-change preservation is covered by the existing
world owner transition and a focused domain check, with native death/new-life
regression preserved. Working role -> log oddities -> next subsystem.
