raw host option validates all three. Original saved-mode restoration remains its
own authority; default species/assets/resources and the Thistletail path remain.

and feet, dorsal/flank osteoderms and a stiff tail. The visible club is adult/old
only; juvenile armor uses a simpler muted presentation. No final anatomy, authored

existing terrain support/+Z controls/camera/needs/rest/drink/destination owners with

animal (adult Thistletail also qualifies, or another immature animal) must have
