# Ordinary hero foraging working draft

Connected play reuses the existing needs suggestion, body-local perception,
single goal controller, movement integrator and eligible shrub interaction. A
hungry body chooses an available imported browse resource within24m. Direct
W/S/A/D/E input cancels automatic movement/contact immediately. Camera location
never supplies the target or grants food. Selected shrub IDs gate auto contact;
auto browse does not enter the drink branch, and the shared ledger/contact
session applies hunger relief once. Existing foliage presentation reflects the
same ledger state. The original drink API defaults remain valid.

Run-ConnectedWorld.ps1 imports the pinned local provisional Basketfern when
available, using the existing AssetRoot option; an absent artifact announces
that foraging affordances are unavailable. Changed artifact hashes fail. Source
assets are not generated or modified. Use -Proxy for the existing proxy body.

Native diagnostic switches on Run.ps1: HeroForagingProbe,
HeroForagingOverrideProbe, HeroForagingCameraProbe; supply Plant. Hunger=.8,
startup positions and timed override/camera initialization are synthetic and
explicit. There are no later body teleports. They exercise ordinary movement and
real imported shrub contacts, not a physical keyboard-driving claim.

A western camera-only startup exposed the current exterior cohort's missing
support tile. Connected terrain now retains bounded tile(1,0), supporting the
existing x104-144/z18-32 cohort while the hero is west ofx0. The original mesh,
body-driven streaming and coarse population activation are unchanged. This is
not generalized regional residency or a broader terrain rewrite.

Draft limits: straight local approach without obstacle planning, coarse radial
sensing and reach, tree-fern browse stand-in, no anatomical feeding/mouth/pose
acceptance. Provisional proxy and existing juvenile animal pace remain. Connected
preview still refuses saves; original saved mode is preserved. Once native role
proof passes, log these limits and move to ordinary rest/recovery.
