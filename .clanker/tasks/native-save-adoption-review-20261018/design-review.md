# Independent admission review — bounded native adoption

The approved contract distinguishes two sources of authority:

- External native world configuration: region identity, generated habitat and its signature, actual resource anchor geometry, required anchor resource kinds, supported species catalog, and bounded reservations/capacities.
- Explicit save-declared legacy continuation provenance: actual retained actor identities/species, valid lifecycle/route/needs snapshots, resource initial quantities and extra legal resources, depletion/history and explicit actor/session ownership. These are validated imported facts, not authenticated historical facts.

For arbitrary legal old saves, no independent immutable original actor manifest exists. Reconstructing their imported admissions from the validated embedded legacy DTO is permitted under this explicit policy. It must not be described as proving historical identity/species authenticity. A coherent legally edited identity/species can be accepted; mismatched payload edits, unsupported enums, conflicting owners and invalid topology must reject.

Previously supported imports remain the compatibility oracle. The new path must not silently restrict to generated original eight, canonical nine-resource quantities, or nonempty populations. New independent constraints apply only where the old native world already required them for legal construction/contact configuration. Missing legacy population continues the old fallback generation behavior if that was the established importer; an explicit saved empty population stays empty.

Capture must derive legacy population, full ledger and session map from one registry continuation without advance or consumption between snapshots. A failed decode/admission/restore must not partially publish clock/world/registry. Startup-only construction can perform work on detached owners before application launch; it must accurately describe that it does not implement hot reload.

Native negative process tests will follow worker GPU release, serialized, against exact pinned executable bytes. Root owns integrated positive historical migration/continuation proof. Reviewer domain probes independently challenge legal custom/empty imports and checksum-recomputed invalid topology/anchors/reservations/owners. Existing file hashes must survive rejected save/load attempts.

Limits remain explicit: one retained native region, no new exterior habitats, no authentication/antirollback guarantee, no power-loss durability, no visual/contact/FPS acceptance.
